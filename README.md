# 서울시 따릉이 이용의 시간, 공간적 불균형 분석

## 연구 목적
본 프로젝트는 서울시 공공자전거 따릉이의 이용 데이터를 활용하여 
시간대 및 지역에 따른 이용량 분포의 불균형을 분석하는 것을 목표로 한다
추가로 대여소 수와 같은 접근성 요인을 통제한 후에도 
시간과 공간적 격차가 존재하는지를 통계적으로 검증한다

불균형 = 용량이 고르게 분포되지 않음

시간대별 이용 집중 (출퇴근 vs 비출퇴근)
평일 vs 주말 차이
계절별 차이
🗺️ 공간적 불균형
구/동별 이용량 격차

접근성(대여소 수 대비 이용량)
