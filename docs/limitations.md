# 한계와 후속 연구

- 대여·반납 흐름 차이는 실제 시점별 재고가 아닌 잠재적 불균형 proxy입니다.
- 대여소 용량, 작업 차량의 출발지·적재량·근무시간, 도로망 이동시간을 직접 반영하지 않았습니다.
- 직선거리 기반 비용은 실제 차량 운행거리와 다를 수 있습니다.
- 상위 불균형 대여소 중심의 웹 데모는 서울 전체 네트워크 결과와 구분해야 합니다.
- 관측된 수요가 품절 때문에 억제된 잠재 수요를 포함하지 못합니다.
- 동일 분기의 설명적 분석이므로 다른 계절·연도에 대한 외적 타당성 검증이 필요합니다.
- 원천 이용 데이터의 대여소 중 기존 좌표 파일에서 검증 좌표가 확보된 곳만 거리 기반 지도·최적화에 포함됩니다. 미매핑 대여소의 불균형 값은 결과 JSON에 별도 보존합니다.

후속 연구에서는 시점별 재고와 거치대 용량, 도로망 시간, 다중 차량 경로, 날씨·행사 변수를 결합하고 날짜 기반 홀드아웃 평가를 수행할 수 있습니다.
