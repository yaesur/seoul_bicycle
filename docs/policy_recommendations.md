# 서울시 공공자전거 재배치 정책 제안

## 정책 목표

흐름 불균형이 큰 시간·권역에 한정된 운영 자원을 선제 배치하면서, 같은 개선량을 달성하는 데 필요한 운송거리와 운행 횟수를 줄이는 것을 목표로 합니다. 현재 권고량은 실제 재고가 아닌 대표일 흐름 proxy이므로 시범운영의 우선순위와 규모를 정하는 근거로 사용합니다.

## 1. 시간대별 선제 재배치

- 출근: 06:00–07:00에 출근 유출 과잉 대여소를 중심으로 사전 공급
- 퇴근: 16:00–17:00에 업무지 유입 과잉 자전거를 주거·환승 수요지로 이동
- 여가: 주말 11:00–12:00에 한강·공원·상업 권역을 별도 운영군으로 편성

매일 모든 대여소를 동일하게 관리하지 않고, 전일·동일 요일의 흐름과 당일 재고를 결합해 우선순위 대여소를 선정합니다.

## 2. 5km 권역형 우선 확인

5km 안에서 과잉·부족 규모가 크고 거리가 가까운 대여소 쌍을 우선 확인합니다. 연결 가능량은 이동 명령이 아니라 현장 확인 가치가 큰 흐름 규모로 해석합니다.

## 3. 현장 확인 후보 표준화

운영 화면은 다음 정보를 하나의 검토 후보 단위로 제공합니다.

```text
출발 대여소 → 도착 대여소
대표일 연결 가능 불균형 / 직선거리
우선순위 점수 / 매우 높음·높음·보통 등급
```

상위 후보부터 실제 재고와 거치대 여유를 확인한 뒤 담당자가 이동 여부와 수량을 결정합니다.

## 4. 단계적 실행안

| 단계 | 기간 | 실행 내용 | 판단 기준 |
|---|---|---|---|
| 데이터 정비 | 1–2개월 | 공식 대여소 ID·좌표·용량·실시간 재고 결합 | 좌표 매핑률 100% |
| 소규모 실증 | 4주 | 2개 권역에서 기존 방식과 교차 운영 | 품절·만차 시간, bike-km |
| 확대 검증 | 8–12주 | 출근·퇴근·주말 운영군 분리 | 이용 실패율, 운영비, 민원 |
| 상시 운영 | 이후 | 일별 재학습·작업지시 자동 생성 | KPI 지속 개선 여부 |

## 5. 성과지표

- 자전거 대여 실패 추정 시간 및 만차 지속시간
- 재배치 후 잔여 절대불균형
- 이동 자전거 1대당 운송거리
- 차량별 총 운행 횟수와 작업시간
- 대여소 서비스 수준의 권역 간 격차
- 예측 권고량과 실제 필요량의 오차

## 정책 적용 전 필수 조건

서울시 실시간 대여소 API의 공식 ID를 기준으로 97% 이상을 매핑했습니다. 남은 항목은 2025년 6월 반기별 마스터로 폐쇄·신설·ID 변경 이력을 보완해야 합니다. 실시간 재고와 거치대 용량을 결합하기 전에는 본 결과를 실제 이동 명령으로 사용해서는 안 됩니다.
