# 데이터 안내

원천 데이터는 서울 열린데이터광장의 공공자전거 대여 이력(2025년 4–6월)을 사용합니다. 약 4.8GB의 원천·중간 데이터는 저장소에 포함하지 않습니다.

## 분석 단위

- 관측 단위: 출발 대여소–도착 대여소–시간 구간별 집계 이용량
- 출근: 평일 07:00–09:59
- 퇴근: 평일 17:00–20:59
- 여가: 주말·공휴일 12:00–18:59
- 흐름 불균형 proxy: `반납 건수 - 대여 건수`
- 정규화 지표: `(반납 건수 - 대여 건수) / (반납 건수 + 대여 건수)`

양수는 해당 기간의 유입 과잉, 음수는 유출 과잉을 의미합니다. 이는 특정 시점의 실제 재고·거치대 부족을 직접 관측한 값이 아닙니다.

## 재현

원천 CSV를 `data/raw_data/YYYYMM/`에 내려받고 다음 순서로 실행합니다.

```bash
python -m src.fetch_station_master
python -m src.build_web_data
```

첫 번째 명령은 `SEOUL_OPEN_DATA_API_KEY` 환경변수가 필요합니다. 공개 저장소에는 개인정보나 API 키 없이 `data/sample/`의 소량 표본과 웹용 집계 결과만 둡니다.
